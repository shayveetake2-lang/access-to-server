Plex Media Server

Self-hosted movie & TV streaming

● Online (Port 32400)

Plex Media Server is actively running. Your full movie and TV show library is accessible from any device — no VPN needed. Just create a free Plex account and ask an admin to send you an invite.

1

Create a Free Plex Account

Go to plex.tv/sign-up and create a free Plex account using your email. No subscription is needed — a free account is all you require to access this server.

2

Ask an Admin for an Invite

Contact the server admin via the ServerFlow dashboard or directly, and provide your Plex account email. The admin will send you a library share invite from within Plex.

3

Accept the Invite & Open Plex

Check your email for the Plex share invitation and accept it. Then click the Open Plex Web App button above, sign in with your Plex account, and the shared library will appear automatically.

4

Browse & Stream

Navigate to Movies or TV Shows in the Plex sidebar. Click any title to begin streaming immediately. Subtitles and audio tracks can be toggled from the player controls.

Troubleshooting
  • › No library showing? Make sure you've accepted the admin's share invite via your Plex email before opening the app.
  • › Playback buffering? Switch the Plex streaming quality to a lower setting (720p or 1080p original) under Settings → Quality.
  • › Server not appearing? Confirm the server is online via the Dashboard. If it just went down, check back shortly or contact an admin.

Ampache Music Server

Self-hosted music streaming

● Online (Port 8888)

Ampache Music Server is actively running. Your full audio library is ready for streaming from any browser or compatible client app. Just ask an admin for an account.

1

Ask an Admin for an Account

Contact the server admin via the ServerFlow dashboard or directly to request a free Ampache music account.

2

Open Ampache Login

Click the Open Ampache button above, or go directly to /ampache/public/login.php.

3

Sign in to Ampache

Enter your Ampache username and password on the login page. If you don't have an account, contact the server admin to create one for you.

4

Browse & Stream Music

Use the Browse menu to explore artists, albums, and songs. Click any track to stream instantly. Create playlists from the Playlist section.

5

Use a Mobile Client (Optional)

Ampache is compatible with many third-party apps via its API. Apps like Symfonium, Ultrasonic, or DSub (Android/iOS) support the Subsonic API that Ampache also exposes. Point them to the server URL above.

API & Integration Info
  • › Ampache REST API endpoint: /ampache/public/server/xml.server.php
  • › Subsonic-compatible API is enabled — use the same server URL in compatible clients.
  • › DAAP (iTunes sharing) is configured at /ampache/public/daap.
Troubleshooting
  • › Login fails? Double-check your Ampache username/password. Accounts are separate from ServerFlow admin accounts.
  • › Page not loading? Confirm MAMP/Apache is running on the server via the Dashboard.
  • › Missing songs? Ask an admin to trigger a catalog update inside Ampache → Admin → Catalog → Update all.
