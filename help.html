How to Use This Site

Deployer

The Deployer is used to initialize a sequence by sending your details to the server.

  • Enter your Name, Contact Info, and a Message.
  • Click Initialize Sequence.
  • If successful, your data will be transmitted and you will receive a welcome message. Ensure your ZeroTier connection is active if you encounter issues.

Host Website

The Host Website section allows you to quickly deploy your web projects to the server.

  • Enter your Project Name (letters, numbers, dashes, and underscores only). This will be the name of the folder created on the server.
  • GitHub Repo: Paste the public URL of a GitHub repository to automatically clone it to your server.
  • Upload .zip: Drag and drop a `.zip` file of your website to automatically extract it to the server.
  • Once deployed, click the provided Visit Live Site link to view your newly hosted website.

Hosted Sites

The Hosted Sites page shows all websites currently live on the server — updated automatically after every deployment.

  • Each card shows the site name, last updated time, and a Visit Live Site ↗ button.
  • A ● LIVE badge means the site has an index file and is accessible.
  • A ⚠ NO INDEX badge means the folder exists but has no entry point — the site may be incomplete.
  • All sites are deployed to the /sites/ subfolder on the server.

Movie Portal

The Movie Portal provides direct access to the Plex Media Server.

  • Click the Launch Media Server button.
  • You will be redirected to Plex, where you can stream available media content.

Diagnostics

The Diagnostics page helps you manually verify the health of the system.

  • It checks if the MySQL database (access_db) is connected and running on port 8889.
  • It tests shell execution and verifies if Git is available.
  • It provides a manual checklist for you to verify ZeroTier network status and Plex routing.

Auto Debug

The Auto Debug page performs automated health checks and offers auto-fix recommendations.

  • It runs checks on Git/Deployer, Database, Plex Server, and SSE (Server-Sent Events) configurations.
  • If any check fails, you will see a detailed error and suggested solutions to fix the issue in your server environment.
