Server Documentation

Complete guide to using the Server Console and all its features

Deployer

The Deployer is the main dashboard for deploying Git repositories. Enter a GitHub repo URL and click Deploy. The terminal shows real-time SSE output of the git clone process.

  • Steps: Enter GitHub repo URL → Click Deploy → Watch terminal output → Click the popup link to visit your site

Host Website

Deploy websites by cloning a GitHub repo or uploading a ZIP file.

  • Enter a unique Project Name
  • GitHub Repo: Paste a public repo URL to auto-clone
  • Upload .zip: Drag and drop a ZIP to extract to the server
  • Visit Live Site link appears on success

Hosted Sites

Shows all websites currently live on the server.

  • Each card shows site name, last updated time, and a Visit button
  • LIVE badge = has an index file and is accessible
  • NO INDEX badge = folder exists but no entry point
  • All sites deployed to /sites/ subfolder

Plex Portal

Direct access to Plex Media Server.

  • Click Launch Media Server to open app.plex.tv
  • Requires Plex running on port 32400

Diagnostics

Manual system health verification.

  • Checks MySQL database connection on port 8889
  • Tests shell execution and Git availability
  • Manual checklist for ZeroTier and Plex

Auto Debug

Automated health checks with fix recommendations.

  • Runs checks on Git/Deployer, Database, Plex, SSE, and Sites directory
  • Failed checks show detailed errors and suggested solutions
