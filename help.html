Beginner Guides & Docs

Step-by-step guides for deploying websites, managing USB drives, and setting up databases.

Dashboard Overview

The Dashboard is the control center for your server. It gives you an immediate bird's-eye view of everything happening right now.

  • Health & Traffic: Monitor your CPU, Memory, Uptime, and active web requests in real-time.
  • Storage: Check how much space is left on your Primary SSD and connected USB drives.
  • Fast Actions: Use the quick buttons at the bottom to clear cache, reload the web server, or ping the database without leaving the page.

App Databases

Manage your backend databases directly from this section.

  • Overview: See all active SQLite and MySQL databases running on the server.
  • Backups: You can create backups of your databases to ensure your data is safe before making big changes.
  • Optimization: Run cleanup operations to shrink database sizes and improve query speeds.

Activity Stream

The Activity Stream acts as a live feed for your server, showing you exactly what is happening under the hood.

  • Live Events: Watch user logins, file uploads, and system events as they happen.
  • Filtering: Use the search or filter options to find specific events (e.g., only show errors or warnings).
  • History: Scroll back to see what occurred on the server while you were away.

System Settings

Tweak the core behavior of your server from the System Settings panel.

  • Environment: Change PHP execution limits, memory bounds, and timezone settings.
  • Security: Update admin passwords or toggle security constraints.
  • Network: Review port bindings and local IP address allocations.

My Live Websites & Deployer

This is where you launch new projects onto the internet!

  • Deploy a Site: Enter any public GitHub repository URL into the deployment form. The server will clone the repository, run build scripts, and publish it automatically.
  • Manage Sites: View all currently hosted websites, see their statuses, and completely delete or re-deploy them with one click.
  • Access Links: Click on a live site to open it directly in a new tab.

Media Player (Plex) & Music Portal

Your server doubles as a personal streaming platform.

  • Plex Media Player: Access your entire movie and TV show library. Plex transcodes video so it plays smoothly on any device.
  • Music Portal (Ampache): A dedicated streaming portal for your personal audio library. Works just like Spotify, but you own the data!
  • Public Access: These portals are open to all visitors, meaning your friends and family can use them without needing server admin credentials.

Server Specs & IP

Find technical details about the machine running your server.

  • Hardware Info: View your CPU model, total RAM, and OS version (e.g., macOS, Linux).
  • Network Identity: Find your local IP address and ZeroTier network IPs so you can connect from other devices on your network.
  • USB Management: External USB drives mounted at /Volumes/USBDrive can be inspected and managed from here.

Diagnostics & Debug Logs

For advanced troubleshooting when things go wrong.

  • Health Diagnostic Check: A one-click automated test that verifies file permissions, database connections, and API endpoints.
  • Server Debug Logs: A raw output of PHP and Apache error logs. If a website crashes, this is the first place you should look!
  • Note: These tools are strictly limited to authenticated server administrators.
